# 🧠 Решение задач NTO BDML

Репозиторий содержит решения трёх задач соревнования NTO BDML (Национальная технологическая олимпиада, направление "Большие данные и машинное обучение").

---

## 📋 Задачи

| Задача | Тип | Краткое описание |
|--------|-----|------------------|
| **C** | Классификация | Предсказание целевой переменной с помощью LightGBM |
| **D** | Восстановление матрицы | Сопоставление городов по частичным данным о расстояниях |
| **G** | Поиск подобия | Нахождение пар похожих таблиц по статистическим сигнатурам |

---

## 🎯 Задача C: Классификация

**Что делает:** Обучает модель классификации на данных с категориальными признаками.

**Пайплайн:**
1. Загрузка и объединение train/test данных
2. Удаление шумовых признаков (`f5`, `f15`, `f37`)
3. Обработка категорий (Label Encoding, заполнение пропусков)
4. Обучение LightGBM с подобранными гиперпараметрами
5. Сохранение предсказаний

**Ключевые параметры модели:**
- `n_estimators=4000`, `learning_rate=0.01`
- `num_leaves=45`, `class_weight='balanced'`

**Используется:** `lightgbm`, `scikit-learn`, `pandas`, `numpy`

---

## 🗺️ Задача D: Матрица расстояний

**Что делает:** Восстанавливает полную матрицу расстояний между городами и находит соответствие между ID городов и их названиями.

**Пайплайн:**
1. Восстановление матрицы через алгоритм Флойда-Уоршелла
2. Получение реальных расстояний (OSRM API + геодезический fallback)
3. Построение графовых признаков для каждого города
4. Сопоставление матриц через венгерский алгоритм

**Ключевые компоненты:**
- `floyd_warshall` — заполнение пропусков
- `linear_sum_assignment` — оптимальное сопоставление
- Геокодинг через Nominatim (кэшируется в `coords.json`)
- Дорожные расстояния через OSRM (кэшируются)

**Используется:** `scipy`, `geopy`, `requests`, `numpy`, `pandas`

---

## 🔍 Задача G: Поиск пар таблиц

**Что делает:** Находит пары таблиц с похожей структурой среди множества CSV-файлов.

**Пайплайн:**
1. Загрузка всех таблиц из папки
2. Вычисление статистических сигнатур для каждой таблицы:
   - Глобальная статистика (среднее, std, медиана, квартили)
   - Гистограмма распределения
   - Строчные и колоночные статистики
   - Корреляционные матрицы (Пирсона и Спирмена)
   - Собственные значения корреляционных матриц
3. Группировка таблиц по размерности
4. Попарное сравнение с взвешенным расстоянием (10 компонент с весами)
5. Жадный отбор уникальных пар

**Веса сравнения:** от 2 до 17 в зависимости от компоненты сигнатуры

**Используется:** `numpy`, `pandas`, `scipy.stats.spearmanr`, `collections`
